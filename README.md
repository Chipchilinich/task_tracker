# TaskManager

### TaskManager — это простое приложение для управления задачами с помощью командного интерфейса. Оно позволяет пользователям добавлять, удалять, редактировать и просматривать свои задачи.

## Установка

1. Склонируйте репозиторий на свой компьютер:
```bash
   git clone https://github.com/username/TaskManager.git
   cd TaskManager
```
3. Устанавливайте зависимости из файла **pyproject.toml** командой: 
```
poetry install
```

## Использование
### Запустите приложение:
```
python task_manager.py
```

### Вводите команды для управления задачами:
```
add - добавление новой задачи.
remove - удаление существующей задачи.
edit - редактирование уже добавленной задачи.
show - отображение списка всех задач.
exit - выход из программы.
```
### Примеры команд
```
Для добавления задачи: add <название_задачи>
Для удаления задачи: remove <номер_задачи>
Для редактирования задачи: edit <номер_задачи> <новое_название_задачи>
Для просмотра всех задач: show
Для выхода из приложения: exit
```
